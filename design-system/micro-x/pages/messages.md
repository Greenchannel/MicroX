# Page Spec: 私信 / 群聊

## 结构

- 双栏：左会话列表（300px，含"群聊"分组与创建按钮）+ 右聊天窗。
- 聊天窗：头部（返回 + 头像 + 名称 + 在线状态 + 转账按钮）→ 消息区（自动滚底）→ 底部输入条（textarea 自动增高 + 图片 + 发送）。
- 会话项：头像 + 名称（含徽章）+ 预览 + 未读胶囊。

## 气泡

- 自己：右对齐，`background: linear-gradient(135deg,#6366F1,#8B5CF6)` 白字，圆角 16px。
- 对方：左对齐，`background: var(--panel)` + 边框，圆角 16px。
- 转账 / 拼手气卡片：独立居中卡片（`payment-card`），金色标题 + 金额 + 领取按钮。
- AI 生成中：对方气泡内三点波浪动画 + "AI 正在思考…"。

## 响应式

- 手机：单栏；`msg-chat.hidden-mobile` 隐藏聊天窗；打开会话移除该类并全屏展示。
- 平板：会话列表收窄至 260px。
