# Page Spec: 管理后台

## 结构

- 顶部 Tab 胶囊条（横向滚动）：用户 / 私信 / 工单 / 举报 / 认证 / AI互动 / 奖励 / 商品 / 公告 / 官方广播。
- 用户管理：搜索行 + 用户行卡片；点击行展开编辑面板（资料 / 头像 / 管理权限 / 发放 / 处罚按钮）。
- 举报 / 认证 / 工单：行卡片（元信息 + 原因/备注 + 操作按钮组）。
- 商品管理：统计卡片 + 设计器（预览区 + 控件区）+ 全部商品列表（缩略图 + 快捷调价）。

## 视觉约束

- 行卡片间距 10px；行内按钮统一小号（12px）。
- 状态标签：`badge-pending`（琥珀待处理）、`badge-resolved`（绿色已处理）、`penalty-tag`（红色处罚）、`admin-tag`（indigo 管理员）。
- 编辑面板插入被编辑行之后，带左侧 3px accent 强调条。
