# Page Spec: 首页（信息流）

覆盖 Master 文件中与本页冲突的规则。

## 结构

1. **顶部吸头**：页标题"首页"（大标题 22px）位于毛玻璃吸顶条内，右侧可放当前 CCB。
2. **发帖框**（登录后）：头像（44px）+ 多行输入（最大 280 字，超出标红计数）+ 图片按钮 + CCB 余额 + 渐变"发帖"按钮。
3. **Tab 分段控件**：最新 / 热门；激活段为白底浮起 + 600 字重。
4. **帖子列表**：无边框行（X 风格），hover 浅色底；操作条为点赞（pink）/ 评论 / 打赏（gold）。
5. **加载更多**：底部居中胶囊按钮；列表首屏加载显示骨架屏。

## 状态

- 未登录：显示登录提示条 + 空状态，不发请求。
- 禁言：顶部红色信息横幅，隐藏发帖框。
- 帖子被删除 / 失败：toast 错误并刷新。

## 视觉约束

- 帖子行间距 `padding:16px 20px`；行内用 8px 间隙。
- 点赞点亮态：`color:#EC4899; fill:currentColor` + 弹跳 300ms。
- 图片帖子：圆角 14px，点击放大（深色灯箱）。
