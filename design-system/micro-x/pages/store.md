# Page Spec: 商店 / 股市

## 结构

- 顶部 Tab：全部 / 头像框 / 聊天气泡 / 头衔 / 文件 / AI陪聊 / 股市（横向滚动胶囊条）。
- 商品区：自适应卡片网格（`minmax(240px,1fr)`）。
- 我的库存 / 我的商品：紧凑行列表（缩略图 + 名称 + 状态 + 操作）。
- 股市：卡片含"现价 / 今日 / 昨收 / 量 / 我的持仓"、SVG 走势、买入/卖出按钮；红涨绿跌。

## 卡片

- `store-card`：白底、1px 边框、16px 圆角、hover 提升阴影。
- `store-preview`：居中预览区（头像框预览 / 气泡预览 / 头衔预览 / 文件图标）。
- 价格：`coin` 数字用 tabular-nums；官方商品金色"官方"标签，限定商品紫色"限定"标签。
